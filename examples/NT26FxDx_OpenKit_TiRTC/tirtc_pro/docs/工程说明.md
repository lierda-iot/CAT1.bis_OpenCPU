本目录包含探鸽 TiRTC Pro 应用业务代码，集成在利尔达 NT26FxDx OpenKit 工程中，面向 NT26F6D0 / F6D_D 平台。利尔达工程提供公共 SDK、底包、板级支持、工具链和构建规则；探鸽提供本目录中的应用及 TiRTC 业务实现。集成位置不改变各自代码的来源和归属。

## 构建方式

在工程根目录的 `Makefile` 中确认项目和底包参数：

```make
export PROJECT  ?= NT26FxDx_OpenKit_TiRTC
export MODEM    ?= NT26F6D0
export MODEMPKG ?= F6D_D
```

在 `examples/NT26FxDx_OpenKit_TiRTC/config` 中设置目标应用及构建模式，例如：

```make
APP_VARIANT ?= pro
BUILD_MODE ?= full
```

完成配置后，在工程根目录执行 `make all`。Pro 模式支持 `full`、`app` 和 `assets`：`full` 生成含外置资源镜像的完整包，`app` 生成正式应用包，`assets` 生成外置资源安装器包。产物目录和后续烧录步骤见[当前设备操作](当前设备操作.md)及[构建与固件](构建与固件.md)。本文不使用旧产品目录中的独立批处理脚本或发布目录作为构建入口。

不能只复制本目录构建；工程还需要利尔达提供的公共 SDK、板级组件、底包和工具链。本板启动及链接兼容处理见 [board_compat](../board_compat/README.md)，资源安装流程见 [resource_store](../resource_store/README.md)。

## 功能边界

当前应用包含 AI 对话、微信及设备音视频电话、平台发起的实时查看和多人对讲。当前一次运行一路媒体会话。AI 普通呼叫默认视频，首页电话快捷入口为语音。多人对讲支持创建或加入房间、成员查看和按住讲话，不包含房间视频。具体操作和限制以[当前设备操作](当前设备操作.md)及各功能文档为准。

软件检查记录见[多人对讲验证记录](多人对讲.md#validation)。软件检查不能代替目标设备上的联网、通话、弱网和音质实机验收。
